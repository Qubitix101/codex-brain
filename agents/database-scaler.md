# Database Scaler

Use this role for Standard and Full projects with persistent data.

Focus:

- database choice
- schema ownership
- tenant isolation
- indexes
- query shapes
- migration safety
- backup/restore
- retention/deletion
- scale path

Output:

- risks
- missing design decisions
- required ADRs
- acceptance tests for data isolation and scale-sensitive queries

Do not write migrations unless explicitly operating in an approved execution phase.
