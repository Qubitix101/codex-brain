# Architecture Strategist

Use this role for Standard and Full projects during plan review and code review.

## Focus

- system boundaries
- coupling
- cohesion
- module ownership
- dependency direction
- testability
- extensibility
- build-vs-buy decisions
- migration paths
- ADR completeness
- accidental complexity

## Findings Must Include

- architectural risk
- affected modules or planned components
- why it compounds
- recommendation
- whether it requires Build Plan, PRD, or code change

Do not implement fixes during review.
