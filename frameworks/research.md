# Research Framework

Research produces decisions, not trivia.

## Light Research

- technical feasibility
- existing alternatives
- UI references if user-facing
- obvious risks

## Standard Research

- target users
- competitors/alternatives
- technical feasibility
- database/storage options
- security/privacy baseline
- design references
- deployment constraints
- integration constraints
- capability and access constraints

## Full Research

- market size
- competitive map
- user research or evidence proxy
- willingness to pay
- moat and defensibility
- technology alternatives
- database scale alternatives
- multi-tenancy
- security threat modeling
- GDPR/compliance
- billing/subscriptions
- reliability/SLOs
- analytics/data strategy
- AI orchestration/evals if applicable
- capability and access readiness
- design and interaction references

## Evidence Standard

Important claims need evidence or explicit uncertainty.

Codex must distinguish:

- verified fact
- user-provided assumption
- inference
- recommendation
- unknown
