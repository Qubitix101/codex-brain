# Trigger Calibration

## Trigger examples

1. “Turn this product idea into an unambiguous Linear issue.”
2. “Interview me and specify the next vertical slice before anyone codes.”
3. “Break this feature into dependency-ordered, observable issue contracts.”
4. “Clarify the acceptance criteria and non-goals for this idea.”
5. “Use `$finn-spec` to prepare one human-reviewable work packet.”

## Non-trigger examples

1. “Implement QUB-42.”
2. “Review PR 91 against its issue.”
3. “Is the loop healthy right now?”
4. “Merge this already approved pull request.”
5. “Explain what this existing function does.”

Expected: trigger only when the requested outcome is a specification or issue
contract. Do not implement, review, merge, or schedule recurring work.
