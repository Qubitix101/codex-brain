# Step 2 - Build Plan Gate

Verify:

- Build Plan exists
- ADRs exist for major decisions
- database scale model exists
- security and GDPR plans exist
- Design DNA is approved when UI exists
- test strategy and traceability matrix exist
- project context and memory are initialized
- distillation plan exists for large artifacts
- next allowed action is clear

If a P0/P1 gap exists, do not decompose into PRDs yet.
